2. Project 1 – Caesar Cipher Tool

Objective

The Caesar Cipher Tool is a Python program that encrypts and decrypts text using a user-provided shift key.

Key Features

Encrypts plaintext using a Caesar Cipher shift.

Decrypts the encrypted text using the same shift.

Handles uppercase and lowercase letters.

Preserves spaces and special characters.

Validates the shift-key input as a whole number.

Checks whether decrypted text matches the original plaintext.

How It Works

The encryption function shifts each alphabetic character forward by the selected number of positions. The decryption function shifts characters backward by the same amount. Non-alphabetic characters are left unchanged.

Technologies / Concepts

Python, Caesar Cipher, basic cryptography, string processing.

Learning Outcome

This project provided practical understanding of basic substitution cipher logic, character manipulation, modular arithmetic, and input validation.

3. Project 2 – Password Strength Checker

Objective

The Password Strength Checker evaluates a password against several basic security requirements and provides a security score and improvement suggestions.

Security Checks

Minimum length of 8 characters.

At least one uppercase letter.

At least one lowercase letter.

At least one digit.

At least one special character.

Detection of commonly used passwords.

Scoring

The program calculates a score out of 5. A score of 0–2 is classified as WEAK, 3–4 as MEDIUM, and 5 as STRONG. Commonly used passwords are immediately identified as VERY WEAK.

Output

The tool displays the security score, password-strength classification, and specific suggestions for missing security requirements.

Technologies / Concepts

Python, password security fundamentals, string validation, conditional logic.

Learning Outcome

This project strengthened understanding of password security requirements, input validation, security scoring, and user-oriented security recommendations.

4. Project 3 – Phishing Triage Tool

Objective

The Phishing Triage Tool analyzes sample email and message characteristics, identifies potential red flags, assigns risk points, and produces a security verdict.

Detection Areas

Sender and domain mismatch.

Lookalike, typosquatted, or combosquatted domains.

Urgency, authority, fear, or greed-based language.

Requests for sensitive information such as passwords, MFA codes, or financial details.

Shortened URLs.

Links using raw IP addresses.

Multiple embedded links.

Dangerous attachment extensions such as .exe, .scr, .js, .vbs, .iso, .bat, .jar, .hta, .cmd, and .ps1.

Fake forwarded email chains.

Risk Classification

SAFE – Close

SUSPICIOUS – Warn User

MALICIOUS – Block Domain & Escalate

The classification is based on the total points generated by detected red flags.

Additional Features

Provides a non-expert phishing triage checklist.

Analyzes multiple sample messages.

Produces a detailed report containing findings, risk score, verdict, and recommended action.

Provides pause-and-verify guidance for suspicious messages.

Technologies / Concepts

Python, regular expressions, URL parsing, phishing indicators, risk scoring, email security, security awareness.

Learning Outcome

This project provided practical experience in identifying phishing indicators, analyzing domains and links, assigning risk scores, and presenting security findings in a structured manner.

5. Project 4 – System Vulnerability Audit

Objective

The System Vulnerability Audit is a Python-based endpoint security assessment tool. It detects the host operating system and performs read-only checks on Windows or macOS systems.

Main Audit Areas

Identity Front Door: Reviews password policy and MFA methods.

Software Decay & Patch Management: Checks operating-system update status.

Human Perimeter: Checks Guest account status, administrator membership, screen-lock hygiene, and shadow IT.

Network & Endpoint Hygiene: Checks firewall status and full-disk encryption.

Security Checks

Windows/macOS operating-system detection.

Password policy and MFA review.

Operating-system patch/update status.

Guest account status.

Administrator group membership and privilege creep.

Screen-lock timeout and physical security hygiene.

Installed application / shadow IT review.

Windows Firewall or macOS Application Firewall status.

BitLocker or FileVault disk-encryption status.

Risk and Reporting

Each finding contains a step, title, severity, CVSS band, technical detail, remediation guidance, and an optional verification command. Findings are sorted by severity and summarized as Critical, High, Medium, and Low.

Report Sections

Flaws Found – diagnosis of detected security issues.

Remediation Actions – recommended treatment for each finding.

Hardened Verification – commands or checks used to verify fixes.

Risk Summary – severity counts and overall system status.

Technologies / Concepts

Python, subprocess, platform detection, Windows PowerShell commands, macOS system commands, CVSS severity bands, endpoint hardening, least privilege, patch management, firewall security, and disk encryption.

Learning Outcome

This project provided practical experience in endpoint security assessment, system hardening, security configuration checks, remediation planning, and structured vulnerability reporting.
